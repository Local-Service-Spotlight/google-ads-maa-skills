## Lessons in one line each

- A back-test with the ledger in hand reached zero interventions; the live cycle with a human in chat did not, and most of the difference was scope, not analysis.
- The hardener is the part of the recipe that has never had a clean pass, on five drafts. That is the argument for keeping it.
- A number typed by hand into a data file is the one number the pipeline cannot check.
- Current state is not history: quality score, policy status and negatives all need the historical or status-reason field, or the report under-counts.
- "Not rendered" in a frozen file and "rendered" in a later ledger row are both true; the record must carry time.
